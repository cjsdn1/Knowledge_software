# 拾知 · 学习助手

手机、平板和桌面可用的学习工作台 MVP。把课件、图片圈选、课堂时间轴、笔记和复习卡片连接起来，并通过内置工具流程完成翻译、解释、整理和保存。

本项目独立位于 `D:\khoj\software`，不依赖也不修改上级 Khoj 应用。后端为 Node.js + SQLite，前端为原生 JavaScript / CSS。网页端无需构建；Android APK 可用本机 SDK 打包。

## 启动

需要 Node.js 22.13+（本机使用 Node.js 24.13.1）。

```powershell
cd D:\khoj\software
npm install
npm start
```

打开 [拾知学习助手](http://127.0.0.1:4317)。Windows 推荐双击 `启动拾知.cmd`：它在后台启动服务并打开网页，不会留下命令行窗口；启动失败时窗口会保留并显示错误，详细日志位于 `data/workstation.log`。重复双击只会打开同一个服务网页。首次启动创建一个空课程，不会生成虚假学习记录。首页的“体验示例课件”会显式导入一份示例材料。

## 模型配置

本地课件解析、笔记、课堂打点、录音保存、手动卡片、词典和计算器不需要密钥。

复制配置文件：

```powershell
Copy-Item .env.example .env
```

在 `.env` 中填写提供商实际支持的模型名称与密钥：

```dotenv
AI_BASE_URL=https://api.openai.com/v1
AI_API_KEY=你的服务端密钥
AI_MODEL=支持文字和图像输入的模型名称
# 可选：提供商支持的转写模型
AI_TRANSCRIBE_MODEL=
# 可选：思考模式开关。DeepSeek 默认 enabled，思维链计入输出 token；设 disabled 可省 token 提速，留空则不发送该参数
AI_THINKING=disabled
```

然后重启服务，并在应用“偏好与权限”中启用“允许模型网络调用”。使用 Chat Completions 兼容协议，以便连接不同提供商；图像以所选区域的 data URL 传入，参见 [OpenAI 官方图像输入文档](https://developers.openai.com/api/docs/guides/images-vision)。转写使用 `/audio/transcriptions`。密钥只从服务端环境读取，不下发浏览器、不写入工作流。

如果希望由电脑本机显卡运行模型，请把 `AI_BASE_URL` 指向电脑上已经部署、支持此协议的本地推理服务，并配置它实际提供的文字/视觉模型。当前项目不自带模型权重：若仍用默认 `https://api.openai.com/v1`，电脑承担上传与调度，推理由云端模型完成。

例如本机推理服务确实监听 `127.0.0.1:1234`、提供 `/v1/chat/completions` 时，可在电脑 `.env` 中填 `AI_BASE_URL=http://127.0.0.1:1234/v1`、`AI_API_KEY=local`（仅作兼容占位）、`AI_MODEL=该服务列出的模型ID`。截图 OCR/公式解释需要支持图像输入的模型；纯文本模型只能处理文字。不要在手机里填写模型密钥，也不要把模型服务端口直接开放到互联网。电脑端 `.env` 改动后要停止旧工作站进程并重新启动，再确认网页“模型连接”显示已配置。

手机到结果的耗时大致是：截图/圈选与上行传输 + 电脑排队 + 每个模型步骤的生成 + 下行/轮询。截图按屏幕实际像素采集；圈选区域在 8 MB 内优先保留无损 PNG，超出时使用高质量 JPEG，必要时才缩小图像。手机页面可见且有未完成任务时约每 2 秒检查一次结果，后台任务在“连接与进度”保留。复杂工作流每个模型步骤顺序执行，所以“图像识别 → 翻译 → 总结”通常比单步慢。要降低延迟，优先用小范围圈选、单步工具和响应更快的模型；同一 Tailscale 网络保持在线。这里是体验优化，不保证固定毫秒延迟；手机应用退到后台时不会持续唤醒网络轮询，回到前台会续查。

未配置模型时，在线工具会明确报错，不返回伪造翻译、模拟 OCR 或演示问答。真实模型、视觉识别效果、供应商兼容性及付费语音转写仍需使用有效配置验收；自动测试只验证协议与控制流程。

## 体验顺序

1. 首页导入自己的 PDF，或点击“体验示例课件”。
2. 在文字区域选中内容，点击“选中文字提问”；图片/PDF 可直接拖动圈选。
3. 未配置模型时，先用“保存选区”创建笔记。配置模型后可翻译、解释、追问，结果自动归档。
4. 只想固定用一个工具时，到“工作台”用下拉菜单选好工具（例如“计算器”“离线词典”，不需要模型），材料与结果都留在该工具的信息流里，可编辑或删除。
5. 在“课堂记录”开启课堂，添加重点、疑问、页码、板书或录音，最后结束课堂生成笔记。
6. “工具调度 → 我的工作流”中创建“计算器 → 保存笔记”，输入 `2 + 3 * 4` 可验证无模型依赖的完整流程。
7. 创建复习卡片，翻开答案并评分；笔记和卡片在服务重启后保留。

应用内快捷键：`Alt+Q` 唤出随手记，`Esc` 关闭弹窗。浏览器录音与桌面屏幕捕获需要受支持的浏览器与 HTTPS 或 localhost。Android 包使用通知栏前台录音服务，分段保存到私有目录；系统强制终止进程时，当前未封口片段仍可能丢失。

## 悬浮窗手机尺寸交互规划页

运行 `npm run preview:overlay`，打开 `http://127.0.0.1:4318/overlay-plan.html`。这是独立的手机尺寸网页原型：工具使用随系统浅色/深色切换的小型卡片下拉菜单；九种工具分别展示操作界面，翻译可点词查看释义，计算器可本地计算，卡片可翻面；文字框与文档入口常驻，截图是单独按钮；确认模拟选区后悬浮窗保留处理结果，再演示同步状态。此页用于规划，不执行真实截图、上传文件或 AI 处理；Android 原生悬浮窗另有对应实现。

## Android 手机软件与电脑配对

已生成 v0.5.3 调试版 APK：`android/build/study-companion-v0.5.3-debug.apk`，也可从 [GitHub Releases](https://github.com/cjsdn1/Knowledge_software/releases) 下载。适用于 Android 9+，电脑需要持续运行本项目的新版后端。现在统一使用一个电脑入口：

1. 在电脑双击 `启动拾知.cmd`。它只在本机 `127.0.0.1:4317` 打开管理网页，并在本机 `127.0.0.1:4319` 准备手机访问端口；不会直接监听整个局域网。首次启动自动生成管理员口令并保存在 `data/mobile-access-key`。
2. 电脑浏览器输入该管理员口令登录（不要将此口令发给手机）。在“偏好与权限 → 电脑服务控制台”开启 Tailscale 异网连接，再到“连接与进度”生成一次性手机配对码；配对码 5 分钟有效。手机填写控制台显示的完整 HTTPS 地址与配对码。
3. 在 Android 安装调试 APK，输入电脑地址和配对码。后续设备令牌加密保存在 Android Keystore；管理员可从同一页面撤销设备。
4. 手机可继续使用原有课程、课件阅读、笔记和复习界面；在“偏好与权限 → 原生工具”开启跨应用悬浮球并授予“显示在其他应用上层”权限。切到其他应用/小程序后轻点球展开卡片面板、拖动移动、长按截图。面板内可选九种工具、直接输入文字、选择 PDF/PPTX/TXT/Markdown 文档，或点“截屏”请求单次系统截图。计算器有按键，翻译有双语与示例点词卡，复习卡片可翻面。文字与文档经本机队列提交到电脑，结果留在悬浮窗并归入课程；文档也会出现在主应用的课程资料中。截图授权后仍停留在当前应用上方，可圈选并处理，结果回到悬浮窗。没有静默读取当前应用内容、无障碍权限或自动注入小程序。每次系统截图都要单独授权；受保护页面可能呈黑屏，应用不会绕过目标软件的截屏保护。课堂录音在通知栏显示并可停止。
5. 没有网络时，手机会将笔记、卡片、课堂打点、文件和学习任务写入按电脑身份隔离的本地队列。恢复连接后自动续传，或在“连接与进度”点击立即同步。发生笔记冲突时保留本机版本，可另存为新笔记。

本机 SDK 构建命令：`npm run android:apk`。默认使用 `D:\Android\android-sdk`、Android 34 平台和 JDK 17，也可配置 `ANDROID_SDK_ROOT`、`JAVA_HOME`。APK 用项目本地的调试密钥签名，仅用于安装和真机验收；上架前应使用正式签名并通过平台审核。当前环境没有连接真机，原生权限与后台行为还需安装后验收。

Android 的跨应用球由前台服务维持，通知栏常驻且可点“停止”；在系统设置撤销悬浮窗权限也会使它失效。系统或某些应用可能在支付、授权、受保护页面隐藏悬浮窗，厂商省电策略也可能终止服务，这些情况下不能保证覆盖。未点击上传前完整截图只在手机私有目录；点击“处理选区”后只将提交的选区以 PNG 或高质量 JPEG 持久化到手机待传队列并分片上传电脑。电脑先保存截图附件和课程笔记，再处理模型任务，完成后回填同一笔记；断线时自动重试。若悬浮窗被系统关闭，可用菜单“最近截图”继续未提交的截图，已提交任务会在恢复连接后重试。请勿把敏感页面截图上传模型。更新 APK 时用同包名和同一调试签名直接覆盖安装可保留应用数据；更换签名必须卸载旧版，卸载会清除本机未同步数据，请先完成同步。

升级到 v0.5.3 APK 后，电脑端代码也必须重启（前端资源已更新）：先在电脑网页停止拾知后台，再双击 `启动拾知.cmd`。截图上传完成后在“我的笔记”可看到“悬浮圈选 · 工具名”；文字与文档处理会生成对应课程笔记。若模型未配置或课堂模式禁用在线工具，相关工具会明确报错；计算器、内置词典与保存笔记仍可按权限运行。

配对仅解决设备身份问题，跨网络传输由 Tailscale 私有 HTTPS 保护。Android 原生桥拒绝公网明文 HTTP 和跳转到其他主机。旧的局域网连接方式仍可手动运行 `npm run start:mobile`，但它不具备网页服务控制台，只适用于可信局域网。

### 自己手机异网实验：Tailscale 私有 HTTPS

1. 电脑和 Android 手机分别安装并登录 Tailscale，加入**同一个 tailnet**。先确认电脑上的 Tailscale 显示已连接，并开启 MagicDNS 与 HTTPS 证书功能（首次使用 Serve 时可能提示在管理页面启用）。此方案使用 `tailscale serve`，**不要使用公开互联网的 `tailscale funnel`**。
2. 双击 `启动拾知.cmd`，电脑网页打开后使用 `data/mobile-access-key` 中的管理员口令登录。在“偏好与权限 → 电脑服务控制台”点击“开启异网连接”。首次/每次配置 Serve 时可能弹出 Windows UAC，请本人确认；只有短暂的 Tailscale 配置步骤提权，Node 学习工作站仍以普通权限运行。控制台会显示手机应填写的 `https://电脑名.…ts.net`。安装/登录 Tailscale 仍需用户自行完成；若将 Tailscale 安装在 `D:\Tools\Tailscale`，程序会自动识别。
3. 在“连接与进度”生成一次性手机配对码。把 APK 安装到手机，手机 Tailscale 显示已连接后，在拾知填上一步的**完整 HTTPS 地址（不加端口）**及配对码。已有局域网配对的手机可重新配对并改存 HTTPS 地址。
4. 关掉手机 Wi-Fi，改用移动数据，先用手机浏览器打开该 HTTPS 地址检查是否可达，再在拾知导入一张图片或一份小课件，查看“连接与进度”的上传和电脑任务；断网后重新联网可测试续传。电脑必须保持开机、Tailscale 在线和工作站运行。若翻译/图像理解要真正返回 AI 结果，还须配置本机模型服务或有效的模型 API；未配置时可先用计算器、词典和笔记验证链路。

若“开启异网连接”一直显示配置中，先确认 Windows 授权窗口没有停在后台，并避免点击黑色命令窗口进入“选择”模式（按 Esc 可退出）。新版配置命令不等待键盘交互，单条 Tailscale 命令最多等待 45 秒；修改代码后要先停止后台再双击启动脚本，旧进程不会自动更新。Tailscale Serve 还要求在其管理台 DNS 页面启用 MagicDNS 和 HTTPS 证书；启用证书可能公开设备及 tailnet DNS 名称，需由账户所有者确认。
若提示 `Serve is not enabled on your tailnet`，电脑服务控制台会显示 Tailscale 官方授权页链接。请账户所有者在该页确认 Serve，回到拾知后重新点击“开启异网连接”；单纯让两台设备显示 Connected 不会自动启用 Serve。

手机接入和 Tailscale 异网连接可以分别在服务控制台开关。关闭异网连接会撤销 Serve 转发；仅停止拾知后台不会自动撤销 Serve 配置，但此时不处理请求。管理员服务控制接口只在电脑本机网页开放，异网手机端口不提供该接口；管理员身份仍需访问口令。此方案目前只对同一个 tailnet 的成员开放；本版仍为单人资料库，不适合给小组成员混用私人笔记。

## 浏览器手机、平板访问

默认仅监听本机。局域网访问需在 `.env` 配置：

```dotenv
HOST=0.0.0.0
PORT=4317
ACCESS_TOKEN=自行设置至少16位随机字母数字口令
```

重启后用同一网络设备打开 `http://电脑的局域网IP:4317`，可以输入访问口令，或使用电脑端生成的一次性配对码。口令须为 16–128 位字母、数字、下划线或短横线。浏览器录音、屏幕捕获和 PWA 安装需要可信 HTTPS 或 localhost。本版是个人/可信家庭网络应用，尚不适合直接裸露到公网。

## 模式说明

- 学习模式：按权限运行内置工具。
- 课堂模式：只记录，后端拒绝工具流程；开始课堂自动进入，结束课堂自动回到学习模式。
- 考试模式：禁用模型、计算器、资料导入和课堂记录，只保留笔记查看与内置词典等本地操作。具体允许范围仍由考试规则决定，本模式不构成合规认证或防作弊锁定。

权限在工具执行前及模型请求返回后校验；关闭网络或切换模式会阻止后续处理，但不能撤回已经发送给模型提供商的请求。

## 数据与备份

电脑数据在 `data/study.sqlite`、SQLite 的 WAL 文件及 `data/uploads`。手机待同步队列（含附件）保存在应用本地 IndexedDB，按电脑身份分别存放；断网时笔记、卡片、课堂记录可继续编辑。Android 的系统分享与分段录音先保存在应用私有目录，收取到队列后原生临时副本才会清除。Service Worker 不缓存私有 API、上传材料或密钥。浏览器本地快照不包含模型密钥。

备份时先停止服务，再复制整个 `data` 目录。Markdown 导出中的附件链接指向本地服务，独立迁移时还需要保留附件。

删除是显式且可核对的：笔记、卡片、流程、运行记录可直接删除，但运行中或仍在电脑队列里的任务会先被拒绝；删除资料时若有笔记或记录引用它，会返回引用计数，并让你选择「保留引用」（只解除来源关联、保留原图文件）或「连同引用一起删除」；删除课程可以先把内容迁移到另一门课，或一并级联删除，且永远保留至少一门课。资料与课程属于破坏面较大的操作，只允许在电脑端以管理员身份执行。每次删除都会写入一条 tombstone，用来阻止离线设备把电脑端已删的记录重新同步回来。

## 尚未实现的后续阶段

Android 调试 APK 已构建，但没有 Android 真机，悬浮授权、截图权限弹窗、后台录音、分享入口和在不同品牌设备上的表现尚待实测。iOS Share Extension/快捷指令接入、自由手写套索、无障碍界面识别、跨应用拖拽、云端多用户账户和商店发布仍需后续阶段。电脑后台任务可以在手机离开页面后继续运行；手机附件在 App 下次打开或回到前台时继续同步，当前未提供系统级后台上传作业。

第三方任意代码插件尚不执行；目前的执行边界是固定内置函数白名单与声明式流程，不能把它称为已完成的第三方插件沙箱。外部插件审核、真实用户评分、付费分成、文献检索引用、独立图表生成、错题本专项模块和完整词典属于后续版本。
