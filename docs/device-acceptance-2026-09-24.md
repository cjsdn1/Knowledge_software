# 手机实机验收记录

设备：23013RK75C，Android 15，1440 × 3200，560 dpi，字体缩放 1.0。
当前安装：v0.5.2 / versionCode 7；覆盖安装保留应用数据。

## 已验证

- ADB 截图、安装、点击正常。
- 悬浮工具面板能从应用内打开。
- 键盘弹出后处理按钮保持可见（device-keyboard-after.png）。
- 图库按钮打开系统照片选择器；选择课件图片后保留面板并显示预览。
- 系统截图授权、圈选、提交切回工具面板成功；本次未复现旧版 recycled bitmap 崩溃。
- 翻译页实际输入的 learning 生成可点击链接；点击后独立词义栏显示 learning 并调用查询，原文保留。
- Android 编译和签名验证成功，13 项既有自动化测试通过。

## 本轮修复

- 窗口最大默认高度从 690 dp 调整为 520 dp，响应 IME 高度，保留底部按钮。
- 移除窗口时不立即 recycle 截图，避免异步绘制使用已回收图片。
- 工具切换复位滚动位置，输出出现时滚动到结果，工具菜单禁止外层抢占滑动。
- 移除翻译页固定示例，实际原文和翻译输出支持英文单词点击。
- 输入框长按选词增加查词动作；词义查询使用独立输出栏，不覆盖翻译。
